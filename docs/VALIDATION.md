# 验证范围

版本：1.1.1。

## 文件和结构

验证技能入口元信息、UI YAML、相对文件引用、代码围栏、文本编码以及分发文件清单。对 ZIP 解压后的每个成员核对文件哈希，技能文件与安装副本逐一比较。

内容检查覆盖文本、文件名和 ZIP 成员，不将二进制压缩文件直接当纯文本搜索。分享内容只保留通用方法、模板、官方资料入口与使用示例。

1.1.0已使用skill-creator校验器检查入口，并用skills CLI 1.7.2执行本地 `add . --list`：识别到唯一的 `website-zero-to-live`。这是技能发现验证，没有执行网站部署，也没有声称所有代理的安装均已实测。

1.1.1加入独立法律声明、README入口及随包分发副本。复核官方法律文本、许可表述与匿名化要求，并执行入口校验、相对链接、清单哈希及安装副本一致性检查。这些检查不构成律师审查或法律效力认证。

## 方法走查

已有人工走查覆盖展示站、账号业务、已有框架续做、保留邮箱的域名迁移、模型额度不足、缺少可选技能、支付回调失败、缺少外部授权、有效授权下的发布以及视频/重计算应用。1.1.0增加个人网站主路线，单独检查非技术岗位作品组织、公开资料边界、没有自有域名时的预览路径，以及AI辅助制作与网站自带AI功能的表述区别。

走查用于检查流程是否具有合理分支与停止条件，不是独立代理评估，也不是实际购买域名并部署了上述网站。真正的交付需在对应项目、账号、预算和运行时中执行并收集证据。

## 不能由这些检查证明的事项

- 任意网站都会成功上线或获得商业效果。
- 所有供应商和技能在未来保持当前参数与兼容性。
- 所有代理宿主都能自动发现同一个安装位置。
- 静态检查能证明完整安全性、外部账户可用性或真实用户体验。

发现失败时保留结果并调整方法，不能把未执行、跳过或模拟结果记为真实验收通过。
