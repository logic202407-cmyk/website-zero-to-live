# 安装与使用

通过README中的skills CLI命令安装，或复制完整技能目录到目标代理公布的技能路径。保留 `SKILL.md`、`agents/`、`references/` 和 `assets/`；刷新技能发现后使用 `$website-zero-to-live`，也可要求代理读取入口的本地绝对路径。

## 产品/运营求职网站

```text
使用 $website-zero-to-live，制作一个用于求职的个人网站并推进上线。
目标岗位是产品或运营，我有一份简历和两份可公开的策划案例。
请突出本人贡献和判断，不编造客户、数据或增长效果。
先用平台地址预览，之后再考虑域名。联系方式只公开邮箱。
```

## 设计、写作或市场作品集

```text
使用 $website-zero-to-live，把我的真实作品整理成个人作品集网站。
每份作品说明任务、本人角色、过程和产物，用手机也能方便阅读。
涉及客户姓名和私人材料的部分先遮盖，公开前让我复核。
本轮先完成网站和预览，再给出域名、续费和上线方案。
```

## 技术岗位求职网站

```text
使用 $website-zero-to-live，制作展示我真实技术项目的个人网站。
突出解决的问题、本人实现、取舍和验证证据，不堆技术关键词。
帮我记录AI参与了哪些步骤、我如何复核及怎样维护网站。
网站本身没有模型功能，不要写成AI推荐系统。
```

## 只有自我介绍，还没有完整材料

```text
使用 $website-zero-to-live，先根据我的自我介绍和一份真实作品做个人网站首版。
缺少的经历或结果标明待补充，不生成虚假的项目来填充。
请选择维护简单的方案，并告诉我后续在哪里修改内容。
```

## 续做已有网站或高级系统

```text
使用 $website-zero-to-live 检查当前仓库并推进上线。
保留现有框架和未提交改动，不重新初始化。
本轮授权本地修复和预览发布，先核对缺少哪些上线证据。
```

账号业务、支付、共享数据或AI工具按实际需求加载通用参考。个人展示站不默认增加这些能力。

域名付款、供应商充值及其他支出需有具体授权；已有有效发布授权不重复询问。缺少云账号时仍应完成可进行的本地实现和验证。模板空字段是项目输入，其他skill属于可选增强，不随包分发原文。
