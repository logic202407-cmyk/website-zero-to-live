# 验证记录

版本：1.1.2。

## 可复现的技术检查

本版本维护的检查覆盖技能入口、源码文档与发布产物。在仓库根目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/release.py build
python3 scripts/release.py check
git diff --check
```

- 入口：技能名称、描述、版本、MIT 许可及必要文件。
- 文档：UTF-8/LF、Markdown 围栏、相对文件链接和最小敏感模式检查。
- 分发：安全 ZIP 路径、成员完整性、单一根目录、清单元信息、逐文件 SHA-256、许可证与源码字节一致性。
- 可重现性：同一来源重复构建得到相同字节；篡改、缺件与不一致应使校验失败。
- 全仓库清单：`SHA256SUMS` 覆盖发布输入及 ZIP/旁路校验文件，清单本身不做递归自校验。

本地结果记录应对应最终文件状态；后续改动须重新构建并复验。CI 配置执行相同检查，远端结果以对应提交的实际运行记录为准。

## 结果的使用范围

上述检查针对技能与分发文件；具体网站的构建、浏览器操作、账号权限、外部服务、HTTPS 及部署记录由对应项目保存。记录应区分真实执行、模拟、跳过与不适用，不以文件校验替代业务验收，也不承诺任意宿主或供应商永久兼容。

敏感模式扫描是辅助检查，仍需人工审阅新增内容与最终差异；它不是完整安全审计、版权鉴定或法律意见。
