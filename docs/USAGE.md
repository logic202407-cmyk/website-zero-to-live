# 安装与使用

复制完整技能目录到目标代理实际公布的技能路径，保留 `SKILL.md`、`agents/`、`references/` 和 `assets/`。刷新技能发现后使用 `$website-zero-to-live`，或要求代理直接读取入口的本地绝对路径。

## 展示站

```text
使用 $website-zero-to-live 制作摄影工作室网站。
用户主要通过手机查看作品和提交预约咨询。
首版不需要账号和在线支付，域名尚未购买。
先完成实现与验证，再提出包含续费价格的准确域名购买方案。
```

## 账号业务系统

```text
使用 $website-zero-to-live 构建团队任务网站。
成员可以创建任务、记录进度、按周复盘，团队之间隔离。
先比较适合的框架、数据库和部署平台，给出预算及维护成本。
域名已有，保留现有企业邮箱记录。
```

## 续做现有项目

```text
使用 $website-zero-to-live 检查当前仓库并推进上线。
保留现有框架和未提交改动，不重新初始化。
本轮授权本地修复和预览发布，先核对缺少哪些上线证据。
```

技能按网站类型选择必要架构和方法，不自动安装所有依赖。域名付款、供应商充值及其他支出需有具体授权；已有有效的发布授权不重复询问。没有云账号时仍应完成可进行的本地实现和验证。

模板中的空字段是待填写的项目输入。其他技能均为可选增强，不随包分发其原文；实际安装时从可信来源获取并保留对应许可。
